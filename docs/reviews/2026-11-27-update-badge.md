Reviewer: Codex (`codex exec -s read-only`), on the uncommitted changes of
`feat/update-badge` against `origin/main`. Scope: bugs and accessibility (WCAG 2.2 AA)

was checked against the code before it was adopted; one held and was fixed, one was
not adopted.
