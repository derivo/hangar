# Review temporary folders of the tests (2026-11-02)

Reviewer: Codex (`codex exec -s read-only`), diff before the commit. Cause: the
tests left every `mkdtemp` folder behind (98,826 folders, 23.9 GB, of which
20.9 GB E2E profiles). Fix: `scripts/test-tmp.ts` as `globalSetup` of Vitest
and Playwright creates `hangar-test-run-*` per run, sets it as the temporary
folder and deletes it at the end.

## Findings

1. **[P1] Windows reads `TEMP`/`TMP`, not `TMPDIR`.** Under Windows the
   folders would have stayed behind and the self-test failed.
   **Fixed:** all three variables are set.
2. **[P2] Second run in the same process.** Cleaning up left the variables
   in place; watch mode or the Playwright UI would have kept using the deleted
   folder. **Fixed:** cleaning up restores the previous values;
   `scripts/test-tmp.test.ts` checks that.

No finding: both tools call the returned function as teardown; Vitest workers,
Electron and session shells inherit the environment; only the recorded own
folder is deleted. Individual unit tests start child processes with their own
`env`; the test creates their folder itself.

## Observed

`pnpm test` (1086 tests) and two E2E specs leave no new `hangar-*` folder. If a
run aborts hard, its `hangar-test-run-*` stays behind. Not run under Windows.
